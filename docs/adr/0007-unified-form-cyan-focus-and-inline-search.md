# Unified form, cyan focus indicator, and inline catalog search

To maximize UX efficiency in WPTUI:
1. Website Name and Website Slug are collected within a single interactive form view: leaving Website Slug blank automatically derives it from Website Name upon confirmation, while explicit input overrides it.
2. The active input border indicator uses a high-visibility bright cyan (`#00FFFF`), replacing the default muted gray vertical bar across all forms.
3. Package catalog search is integrated directly into the MultiSelect option list as a terminal option (`[Search catalog / Type to search]`), removing the redundant confirmation prompt step.
